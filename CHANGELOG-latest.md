## Forever Planner 0.5.1

If you haven't restarted the game since 0.5.0, **restart once** (0.5.0 added new files). After that, `/reload` is enough.

- Each class without its own plan yet now has a recommended spec in the setup window: Hunter Beast Mastery, Mage Frost, Paladin Retribution, Priest Discipline (as in the Priest brief), Rogue Combat, Shaman Enhancement, Warrior Arms. Druid (Feral) and Warlock (Affliction) are unchanged.
- Shorter plan window title for the shared route.

### 0.5.0: a plan for every character
- Every character, every class, both factions: a levelling route from your race's starting zone to 60 (Polestar's routes), quests matched by quest ID.
- One-time setup window on first login (spec, group quests); `/fp setup` changes it.
- Talents for all nine classes; the next pick glows on the talent window.
- Places, trainers, flight paths and levels tick themselves; the waypoint follows the next goal.
- Class quests (pets, forms, class items) offered on the tracker at their level; `/fp side`.
- Warlock plan: five-key macros per spec, trainer notes, levelling gear.
- Druid: your own route still runs from 21; existing characters are caught up automatically (`/fp catchup undo`).
